# tatami

macOS 視窗管理工具：每個 space 一份版面、格線面板、拖曳吸附。

## 安裝

```sh
brew tap mikimoto/tatami
brew trust mikimoto/tatami
brew install --cask tatami
```

裝好之後到「系統設定 → 隱私權與安全性 → 輔助使用」打開 Tatami，再重開一次 app。

設定放在 `~/.config/tatami/`，範本見 [`examples/layout.json`](examples/layout.json)。

下載檔在 [Releases](https://github.com/Mikimoto/homebrew-tatami/releases)。
